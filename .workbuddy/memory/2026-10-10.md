# 2026-10-10

## 构建 Release 版本（C++ / CMake / MSVC）

- 项目：desktop-audio-recorder（WASAPI Loopback 采集 -> PCM16 -> Media Foundation MP3 编码），Windows Win32 GUI。
- 工具链：CMake 4.4.0 + Visual Studio 18 Professional(2026) MSVC 14.51.36231 + Windows SDK 10.0.26100.0。
- 关键坑：本机沙箱拦截 `reg.exe`，导致 `vcvars64.bat` 无法探测 Windows SDK，`CMAKE_MT-NOTFOUND`、`rc` 缺失，编译器检测失败；VS 生成器同样探测不到编译器。
- 解决：不调用 vcvars，改为在批处理中显式设置 PATH/INCLUDE/LIB（MSVC bin + Windows Kits bin/Include/Lib），用 `NMake Makefiles` 生成器 + `CMAKE_BUILD_TYPE=Release`。脚本：根目录 `build_release.bat`。
- 产物：`build/desktop-audio-recorder.exe`（约 316 KB，x64）。CMakeLists 用 `/MT` 静态链接 CRT，无 VC++ Redist 依赖。
- 正常（非沙箱）环境可直接用：`cmake -S . -B build -G "Visual Studio 18 2026" -A x64 && cmake --build build --config Release`。
